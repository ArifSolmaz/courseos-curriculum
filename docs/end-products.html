MechaSense Studio

"Give it sensor data, get a fault report."
A command-line tool that ingests raw sensor CSVs (temperature, RPM, vibration, IMU), validates and cleans the data, detects anomalies and threshold crossings, generates annotated time-series plots, and exports a structured fault report — all with one function call.

# Architecture (after OOP)
CSVDataSource → loads CSV, returns Dataset
RuleCleaner → applies configurable rules, reports drops
└─ strategies: DropMissing, DropOutOfRange, DropSpikes
EventAnalyzer → detects threshold crossings, peaks, correlations
Plotter → generates timeseries + summary figures
Reporter → exports JSON + Markdown + cleaned CSV

# DSA optimization
EventIndex → sorted list + bisect for O(log n) range queries
TopKHeap → heapq.nlargest for top anomalies without full sort

AutoDashboard Reporter

"Give it any sensor CSV, get a dashboard. Any device, no code changes."
