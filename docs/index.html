🛟 Falling behind?

Can't finish the standard target? Finish the must-pass core — that keeps you safe. Can't even do that? Submit a recovery ticket. You get 3 per semester at full credit. After that, capped at core level. The system catches you — but you have to reach out.

Your repo — you own it from day one

On Week 1, you get your own private GitHub repository through GitHub Classroom. This is your project's home for the next 2 years. Nobody else touches it — it's yours.

How you get it
  1. Instructor creates a GitHub Classroom assignment
  2. You click the invite link
  3. GitHub creates your private repo from the template
  4. You clone it, open notebooks in Colab, start coding
  5. Push your work every week — that's your submission
