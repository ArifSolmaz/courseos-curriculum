# GitHub Classroom Template Repo

## What goes in the student template repo

When creating a GitHub Classroom assignment, you create a **template repository** that every student/team forks. This template should contain the starter files — NOT the instructor materials.

---

## Include in the template

```
README.md                          ← student-facing README (from README-2.md)
notebooks/
  cp1/                             ← only the current semester's notebooks
    W01_core.ipynb
    W01_studio_robotics.ipynb
    W01_studio_data.ipynb
    W01_studio_simulation.ipynb
    W01_studio_space.ipynb
    W01_studio_iot.ipynb
    W01_check.ipynb
    W01_homework.ipynb
    ... (all 14 weeks)
src/
  project_template/                ← students rename to their project
    __init__.py
    config.py
    io.py
    cleaning.py
    analysis.py
    plotting.py
    reporting.py
    core/                          ← empty __init__.py (used in Year 2)
    dsa/                           ← empty __init__.py (used in Year 2)
tests/
  test_pipeline.py                 ← starter tests
data/
  raw/                             ← empty (students add their data)
  cleaned/                         ← empty (generated by pipeline)
reports/
  figures/                         ← empty (generated by pipeline)
  benchmark/                       ← empty (used in Year 2)
.gitignore
```

## Exclude from the template

```
instructor/                        ← all instructor materials
course-platform/                   ← Flask admin platform
course-content/generate_*.py       ← notebook generators
course-content/nb_utils.py         ← generator utilities
landing-variants/                  ← design experiments
docs/                              ← landing page (separate from student repos)
COURSEOS-3.md                      ← instructor governance doc
INSTRUCTIONS.md                    ← meta-doc
PROJECT_BANK.md                    ← optional variants (instructor reference)
```

## How to create the template

### Option A: Script (recommended)

```bash
# From the courseos-curriculum repo root
mkdir -p /tmp/student-template
cp README-2.md /tmp/student-template/README.md
cp -r course-content/notebooks/cp1 /tmp/student-template/notebooks/cp1
cp -r course-content/src /tmp/student-template/src
cp -r course-content/tests /tmp/student-template/tests
mkdir -p /tmp/student-template/data/{raw,cleaned}
mkdir -p /tmp/student-template/reports/{figures,benchmark}
cp course-content/.gitignore /tmp/student-template/.gitignore 2>/dev/null

# Create a new repo from this
cd /tmp/student-template
git init
git add -A
git commit -m "Initial template for CP1"
gh repo create mechatronics-2026/cp1-template --private --source=. --push
```

### Option B: Manual on GitHub

1. Create a new repo on GitHub (e.g. `mechatronics-2026/cp1-template`)
2. Upload the files listed in "Include" above
3. In repo settings → check "Template repository"
4. In GitHub Classroom → use this repo as the assignment template

## Per-semester templates

| Semester | What to include in notebooks/ | What to add to src/ |
|----------|------------------------------|---------------------|
| CP1 | `notebooks/cp1/` only | Base template (stubs) |
| CP2 | Add `notebooks/cp2/` | Students already have working v1 |
| OOP | Add `notebooks/oop/` | Ensure `src/project/core/` exists |
| DSA | Add `notebooks/dsa/` | Ensure `src/project/dsa/` exists |

### For continuing semesters

Don't create a new repo — update the existing template and have students pull:

```bash
# In the template repo
cp -r course-content/notebooks/cp2 notebooks/cp2
git add notebooks/cp2
git commit -m "Add CP2 notebooks"
git push

# Students pull the update
# (share these instructions with students)
git remote add template https://github.com/mechatronics-2026/cp1-template.git
git pull template main --allow-unrelated-histories
```

Or simply have students download the CP2 notebooks from the course-content repo and place them in their own repo manually.

## Student instructions (give them this on Day 1)

```
1. Click the GitHub Classroom invite link shared by your instructor
2. Accept the assignment — GitHub creates your private repo
3. Clone it: git clone https://github.com/mechatronics-2026/cp1-project-YOURTEAM.git
4. Open notebooks in Colab:
   - Go to colab.research.google.com
   - File → Open notebook → GitHub
   - Paste your repo URL
   - Select the notebook you want
5. After working in Colab: File → Save a copy in GitHub
   Or: download .ipynb and push manually with git
6. Your code goes in src/ — notebooks should import from src/
```
