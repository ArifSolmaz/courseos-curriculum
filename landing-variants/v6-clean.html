Your journey

How it works

You keep one GitHub repository for two years. Every week you open a Colab notebook, learn a concept, and apply it to your project. By the end, you have a portfolio-quality tool that you built from scratch. There are no exams — your grade comes from what you build and what you can explain.

Year 1

CP1: Start from print("hello") and by Week 14 you have a working data pipeline. Every week adds one concept: variables, conditionals, loops, functions, file I/O. Each session is 5 hours.

CP2: Your v1 works but it's fragile. Now you add schema validation, configurable cleaning, professional plots, reports, tests, and move all code into /src.

Year 2

OOP: Refactor v2 into components — DataSource, Cleaner, Analyzer, Plotter, Reporter. Learn design patterns, write pytest tests, build a plugin system. Sessions are 3 hours.

DSA: Find the bottleneck and optimize it — hash tables, heaps, binary search, trees. Prove improvement with benchmarks, Big-O analysis, timing plots.

Typical week

  1. Open the Core Notebook in Colab — learn the concept
  2. Open your Studio Notebook — apply it to your project
  3. Finish the must-pass core first, then standard, then stretch
  4. Run the Universal Check — pass or fail
  5. Fix failures in /src, not in the notebook
  6. Complete the reflection and submit
  7. Do the Homework before next week

What if I fall behind?

Every week has three levels. Can't finish the standard target? Finish the must-pass core — that keeps you safe. Can't even do that? Submit a recovery ticket. You get 3 per semester with full credit. After that, weeks are capped at core level. Nobody fails silently — but you have to show up.

Tracks

Explore all 5 during Weeks 1–2. Confirm by Week 3. Locked for the rest of Year 1. One exceptional reset possible before Year 2. No changes during OOP or DSA.

Grading

  • Weekly submissions + checks: 50%
  • Quizzes / oral explain-your-code: 20%
  • Release demo: 20%
  • Professional habits: 10%

Teamwork is allowed but understanding is individual. Can't explain the code? You get the penalty.

AI tools

If allowed: disclose usage, explain everything. "It runs" is not enough — you must know why.
